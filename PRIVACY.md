# Privacy Policy for HTTP Cats Extension

**Last Updated: January 31, 2026**

This Privacy Policy describes how the HTTP Cats Extension ("we", "us", or "our") handles your information.

## 1. Data Collection

We do **not** collect, store, or transmit any personal data, browsing history, or user information.

## 2. Permissions Usage

To function correctly, this extension requires specific permissions:

* **webRequest / webNavigation:** These permissions are strictly used to detect HTTP status codes (such as 404 or 500) associated with your navigation. We do not log, store, or share your browsing history.
* **Host Permissions:** Required to detect errors on websites you visit.

## 3. Third-Party Services

This extension fetches images from **http.cat**. When an error is detected, a request is made to `https://http.cat/[status_code]`. Please refer to http.cat's privacy policy for their data handling practices.

## 4. Contact

If you have any questions about this Privacy Policy, please contact us via the support section on the Chrome Web Store.
